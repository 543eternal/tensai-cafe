# ☕ 天才カフェ　サイト＆運営ツール 使い方ガイド

「不安ベイビーズ」のみなさんに、安心して今を生きている“天才”たちの光を届ける『天才カフェ』の公式サイトと運営ツール一式です。

このサイトは、**専門知識がなくても「かんたん運営ツール」の入力フォームに文字を入れるだけ**で、
- 新しいイベント（会場／オンライン／両方）の追加
- 天才さん（ゲスト）の追加
- 参加者の声・アーカイブ動画・レポートの追加
- 公式LINE・Instagram・X・メルマガ・前日リマインド文の作成
- SNS告知画像・ストーリーズ画像・バナー画像の作成

がすべてできるようになっています。

---

## 📁 ファイルの役割

| ファイル / フォルダ | 中身 | ふだん編集する？ |
|---|---|---|
| **`天才カフェ_運営ツール/index.html`**（別フォルダ） | **かんたん運営ツール（編集・告知文・告知画像作成）** | ✅ **手元のPCで使う道具箱** |
| `config.js` | 公式LINE・申込フォーム・InstagramなどのURL | ✅ 最初に1回 |
| `data/events.json` | イベント＆過去アーカイブのデータ | ✅ ツールで作って貼りつける |
| `data/guests.json` | 天才さん（ゲスト）のデータ | ✅ ツールで作って貼りつける |
| `data/voices.json` | 参加者の声のデータ | ✅ ツールで作って貼りつける |
| `index.html` | トップページの想い・メッセージ・よくある質問 | ときどき |
| `images/` | るみさんの写真・ゲスト写真・イベント画像 | ときどき |
| `style.css` / `script.js` | デザインと自動表示のしくみ | ❌ 編集不要 |

## ✨ このサイトの便利な自動機能

1. **開催日が過ぎると、自動で「これまでの天才カフェ（アーカイブ）」へ移動します**
   - イベント終了後に手動で移動させる必要はありません。
   - 終了後にYouTubeのURLや開催レポートを足すと、モーダル内で動画が再生できるようになります。
2. **「会場」「オンライン」のしぼりこみが自動で動きます**
   - 「会場＋オンライン（ハイブリッド）」にしたイベントは、どちらのボタンでも表示されます。
3. **ゲストとイベントが自動でつながります**
   - イベント詳細を開くとその回のゲストが表示され、タップするとゲストのプロフィールが開きます。
   - 逆にゲストのプロフィールを開くと、その方が登場するイベント一覧が表示されます。
4. **個別イベントへの直リンクが作れます**
   - `https://サイトのURL/?event=イベントID` をシェアすると、開いた瞬間にそのイベントの詳細画面が開きます（告知文ツールで自動で作られます）。

## 🛠️ 1. イベント・ゲスト・参加者の声を追加する（かんたん運営ツール）

JSONの記号（`"` や `,`）を直接書く必要はありません。

1. `tools/index.html` をブラウザで開きます。
   - 公開後なら `https://ユーザー名.github.io/rumi-menu/tensai-cafe/tools/` をブックマークしておくと、スマホやパソコンからいつでも開けます。
   - 手元のパソコンで `tools/index.html` をダブルクリックして開いても動きます。
2. 上のタブ **「1. かんたん編集（イベント・ゲスト追加）」** を選びます。
3. 編集したい種類を選びます：
   - **📅 イベント一覧（`events.json`）**
   - **🌟 天才さん・ゲスト（`guests.json`）**
   - **💬 参加者の声（`voices.json`）**
4. **「＋ 新しく追加」** を押して、右側のフォームに入力します。
   - 順番を変えたいときは、左のリストの **「↑」「↓」** ボタンを押します。
   - 前回のイベントと似た内容なら **「複製する」** ボタンが便利です。
5. 入力が終わったら、画面の一番下にある **「📋 完成したJSONをコピー」** を押します。
6. GitHubで対応するファイル（例：`tensai-cafe/data/events.json`）を開き、✏️（鉛筆マーク）を押して、中身をぜんぶ消してから貼りつけて「Commit changes」を押します。

## 📣 2. イベント告知文・SNS投稿・告知画像を作る

### 告知文・リマインド文を作る
1. `tools/index.html` の上のタブ **「2. 告知文・SNS・リマインド作成」** を開きます。
2. 「告知したいイベントを選ぶ」からイベントを選びます。
3. 次の5つの文章が自動で作られます：
   - **💬 公式LINE 配信メッセージ**
   - **📸 Instagram 投稿文（ハッシュタグ付き）**
   - **🐦 X（旧Twitter）投稿文**
   - **✉️ メルマガ・ブログ用 案内文**
   - **🔔 申込者への前日・当日リマインド連絡**
4. 必要に応じて画面上で言葉を足し、**「📋 コピー」** を押してLINEやSNSに貼りつけます。

### 告知画像・ストーリーズ画像を作る
1. `tools/index.html` の上のタブ **「3. 告知画像・バナー作成」** を開きます。
2. イベントを選ぶと、タイトルや日時、ゲスト名が自動で画像に入ります。
3. 用途に合わせてサイズを選べます：
   - **Instagram 投稿（正方形 1080×1080）**
   - **ストーリーズ・リール表紙（縦長 1080×1920）**
   - **イベントバナー・OGP・X（横長 1200×630）**
4. ゲストのお写真があれば「ゲスト写真・アイコン写真」から選ぶと、丸くきれいに切り抜かれて配置されます。
5. **「📥 画像をダウンロード（PNG）」** を押すと、画像が保存されます。

## 📝 3. イベント申込み＆申込者の管理（Googleフォーム＋スプレッドシート）

無料で使えて、るみさんがスマホからも確認しやすい **Googleフォーム ＋ Googleスプレッドシート** の組み合わせをおすすめしています。

### ステップA：Googleフォームを1つ作る
1. [Googleフォーム](https://docs.google.com/forms/) で新しいフォームを作ります（タイトル例：「天才カフェ お申込みフォーム」）。
2. 次の質問を作ります：
   - **参加するイベント**（記述式 または プルダウン）
   - **お名前**（記述式・必須）
   - **メールアドレス**（記述式・必須）
   - **ご希望の参加方法**（ラジオボタン：会場参加 ／ オンライン参加）
   - **ひとこと・ご質問**（段落・任意）
3. 右上の「送信」→ 🔗（リンクマーク）からURLをコピーし、`config.js` の `formUrl` に貼りつけます。

> 💡 **裏ワザ（イベント名の自動入力）：**
> Googleフォーム右上の「︙」→「事前入力したURLを取得」を開き、「参加するイベント」の欄にテスト文字を入れて「リンクを取得」を押します。
> コピーしたURLの中にある `entry.123456789` のような番号を `config.js` の `formEventEntry` に入れておくと、サイトの「このイベントに申し込む」ボタンを押したときに、**イベント名が最初から自動入力された状態**でフォームが開きます。

### ステップB：スプレッドシート連携＆自動返信メール（任意）
1. Googleフォームの「回答」タブ → **「スプレッドシートにリンク」** を押します。
2. 開いたスプレッドシートの上部メニュー **「拡張機能」→「Apps Script」** を開きます。
3. もともと書いてある文字を消して、`gas/apply-manager.gs` の中身をまるごと貼りつけます。
4. 上のほうにある `adminEmail`（るみさんのメールアドレス）や `paymentGuide`（振込先などの案内）を書きかえて、💾（保存）を押します。
5. 左メニューの ⏰（トリガー）→ 右下の **「＋ トリガーを追加」** を押し、以下のように設定して保存します：
   - 実行する関数：`onFormSubmit`
   - イベントのソース：`スプレッドシートから`
   - イベントの種類：`フォーム送信時`
6. これで、申込みが入るたびに **申込者へ控え＆お支払い案内メールが自動で届き、るみさんにも通知メールが届きます**。スプレッドシートには「入金・対応状況」列も自動で作られます。

## 💳 4. 有料チケット販売（Peatix・Stripe等）を使う場合

銀行振込だけでなく、事前カード決済やチケット販売サービスを使いたい場合は、次のどちらでも簡単に連携できます。

- **方法①：Peatix（ピーティックス）や こくちーず を使う**
  - Peatix等でイベントページを作り、そのURLを運営ツールの **「有料チケット販売URL（`ticketUrl`）」** に入れます。
- **方法②：Stripe Payment Links（ストライプ決済リンク）を使う**
  - Stripeで商品の決済リンク（URL）を1つ発行し、運営ツールの **「有料チケット販売URL（`ticketUrl`）」** に入れます。

`ticketUrl` にURLを入れると、イベント詳細画面に金色の **「チケットを購入して申し込む」** ボタンが自動で表示されます。

## 🌐 5. 無料で公開する方法（GitHub Pages）

前回の「るみ｜できること」サイトとまったく同じ手順で、**`tensai-cafe` フォルダの中身だけをアップロード**して公開できます（`天才カフェ_運営ツール` フォルダは手元のパソコンに置いておくだけで、公開する必要はありません）。

### 最初の1回だけ：公開の手順
1. [GitHub](https://github.com/) にログインし、右上の「＋」→ **「New repository」** を選びます。
2. **「Repository name」** に **`tensai-cafe`** と入力します。
3. **「Public」** を選び、下の **「Create repository」** を押します。
4. 次の画面にある **「uploading an existing file」** という青い文字をクリックします。
5. パソコンの **`tensai-cafe` フォルダを開き、その中にある7つの項目**（`index.html`、`style.css`、`script.js`、`config.js`、`README.md`、`data` フォルダ、`images` フォルダ）をすべて選んで、GitHubの画面にまとめてドラッグ＆ドロップします。
6. アップロードが終わったら、下の緑色のボタン **「Commit changes」** を押します。
7. 上のメニューの **「Settings」** → 左メニューの **「Pages」** を開きます。
8. 「Branch」のところで **`main`** と **`/ (root)`** を選び、**「Save」** を押します。
9. 1〜3分ほど待ってページを再読み込みすると、上に **`https://543eternal.github.io/tensai-cafe/`** という公開URLが表示されます！

> 💡 すでに `index.html` と `config.js` のURLは `https://543eternal.github.io/tensai-cafe/` に合わせて設定済みですので、リポジトリ名を `tensai-cafe` にすれば書きかえ不要でそのままつながります。
